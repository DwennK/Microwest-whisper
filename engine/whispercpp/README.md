# Desktop transcription resources

The directory name is retained for compatibility. Release builds bundle FFmpeg, its build information, and third-party notices. Parakeet Ultra runs in the application through sherpa-onnx. Its model files are downloaded by the app on demand.

Use `python3 scripts/fetch-whispercpp-binaries.py` to fetch FFmpeg for your platform, then `npm run prepare:whispercpp` to stage the resources for Tauri.
